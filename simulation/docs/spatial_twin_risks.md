# Digital Twin — Implementation Risk Register

Companion to `spatial_twin_design.md` (approved) and `spatial_twin_plan.md`.
Each risk names its mitigation and the **tripwire** (the guard test that fires if it happens).
Constraint frame: FacilityState is the only dynamic truth source; USD is projection only;
deterministic replay and RNG neutrality are preserved end to end.

| # | Risk | Mitigation | Tripwire | Residual |
|---|---|---|---|---|
| R1 | **USD determinism.** pxr text serialization drifts (float formatting, field ordering, customLayerData dict order) → byte-identity proof collapses. | `usd-core==26.8` exact pin; Task 4 spike is a **release blocker**, gating all of Phase B; opinions pre-sorted; customLayerData built from sorted inputs; no wall-clock/uuid anywhere. | `test_usda_text_serialization_is_byte_deterministic`; build-twice byte tests in Tasks 8/9. | Same-machine proof only; cross-machine reproducibility unverified until a second machine builds. Version bumps re-run the spike before re-pinning. |
| R2 | **pxr dependency boundaries.** pxr types leak into pure modules (stream/placement/mapping), or sim types leak into the package → the twin stops being copyable to a render host and the telemetry-ready claim dies. | Mapping emits plain Python values; only `base.py`/`overlay.py` touch pxr; package never imports `nxt_*`/sim libs (file-contract coupling). | `test_pure_modules_import_with_sim_and_pxr_blocked` (find_spec blocker — the 3.12+ API, not the removed `find_module`), `test_twin_source_never_mentions_sim_packages`, `test_no_upstream_file_mentions_twin`. | If usd-core is absent, USD tests skip — CI must install the `twin` extra or the Phase B guards silently don't run. |
| R3 | **Artifact reproducibility.** Capture output differs across runs (RNG perturbation, dict ordering, partial writes) or silently diverges from the benchmark episode. | Capture mirrors `replay_episode`'s exact recipe; snapshots only via RNG-neutral `build_facility_state`; sorted-keys compact JSON; whole-file writes. `git_commit` in meta means byte-repro holds within a working tree, not across commits — tests run capture twice in one session. | `test_capture_is_byte_reproducible`, `test_capture_matches_viewer_replay_events_and_length` (event-log equality **is** the trajectory/RNG-neutrality proof), `test_capture_agrees_with_viewer_frames_on_shared_fields`, `test_capture_script_never_calls_rng_drawing_accessors`. | Episode re-runs are slow (`pytest -m slow` tier); devs skipping slow tests locally lose the neutrality guard until CI. |
| R4 | **Viewer synchronization.** Briefing panel shows the wrong step (off-by-one: n_steps+1 snapshots vs n_steps frames), or the sidecar goes stale when `decisions.py` changes after capture. | Match by `t_s`, never frame index (`briefing_for_time` = latest record ≤ t); sidecar is demo-tier, outside `reports/digital_twin/`, stamped with `git_commit`, regenerate-only — regenerate before any demo; panel is additive (sidecar absent → viewer unchanged). | `test_load_and_lookup_by_time`; Task 11 manual scrub check on a disruption episode. | Staleness enforcement is procedural (regenerate before demo), not mechanical, in v1. |
| R5 | **Real sensor compatibility.** The stream contract accretes sim-only semantics, so a real site can't emit it without lying. | The dynamic payload is `FacilityState.to_dict()` verbatim — a contract that already imports no simulation libraries and carries the sensed-vs-true split (`clean_sensed`) real sensors will fill. Builder consumes files only; swapping the producer touches zero builder code. | `validate_stream_meta` fail-loud; mapping's unknown-key rejection catches payload drift in both directions. | v1 meta requires `policy`/`seed` (sim-driver context). A telemetry adapter is a stream-schema v2 decision (documented seam, design §5) — do not pre-build it. |
| R6 | **Second source of truth.** Placeholder geometry read as site fact; hand-edited `.usda`; `estimates.usda` filling early; briefings becoming a decision record; twin and viewer harnesses drifting apart. | Conflict rule (twin wrong by definition; delete-and-rebuild); `nxt:provenance="placeholder"` + DISCLAIMER in `customLayerData`; input-SHA256 manifest makes hand-patching detectable; recommendations live only in the demo-tier sidecar; estimates layer reserved and empty. | `test_derivation_audit_every_nxt_attr_is_in_the_table`, `test_estimates_layer_exists_and_is_empty`, `test_base_layer_geometry_equals_layout_positions`, `test_no_physics_schemas_applied`, cross-harness equality (R3), upstream no-mention scan. | Provenance tags are invisible in a rendered frame; demo narration must state "placeholder geometry" out loud — social enforcement, by design. |

Standing rule for all six: when a tripwire fires, fix the twin — never the upstream. Upstream
packages are frozen; a failing guard is evidence about this layer only.
